Matt's preferred voice for presentation/talk-track scripts (confirmed by him rewriting a slide himself as the reference):

- **No fourth wall.** Never refer to the slide-as-artifact ("the answer is the tag on this slide", "that last picture", "as you can see", "this band/box"). Weave content into what the speaker says about the *subject*. Pointing at a diagram element while describing the system is fine; naming slide/deck design artifacts is not.
- **Plain, structural, declarative.** Describe the system layer-by-layer / component-by-component with confident factual statements. Light purpose clauses ("for a permanent archive", "the moment it arrives") instead of selling.
- **No rhetorical questions** ("Why does that matter to you?"), **no effusive adjectives** ("battle-tested", "de-risked", "non-negotiable"), no metaphor scaffolding ("I'll walk you into each room").
- **Third person, not direct address.** "The customer" / "a customer" rather than "you"; minimal "we".

**Why:** he delivers a natural spoken narrative (possibly from memory, not read off the deck) to a senior, non-technical audience; sober precision reads as a real platform, not marketing.

**How to apply:** match this register when drafting or revising any script for him. See [[gartner-mq-tech-overview]].
